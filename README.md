# ระบบจัดตารางสอนอัตโนมัติ วิทยาลัยการอาชีพปัตตานี
### Pattani Industrial and Community Education College – Smart Timetable Management System

ระบบจัดตารางสอนและบริหารจัดการเวลาเรียนอัตโนมัติสำหรับวิทยาลัยการอาชีพปัตตานี พัฒนาเป็น Web Application แบบ Full-Stack พร้อมฐานข้อมูลจริง SQLite อัลกอริทึมแก้ปัญหาข้อจำกัดทางวิชาการ (Constraint Satisfaction Problem - CSP) ระบบตรวจสอบตารางชนแบบ Real-Time และระบบรายงานการส่งออก/นำเข้าข้อมูลตามมาตรฐานสถานศึกษาอาชีวศึกษา

---

## 🌟 คุณสมบัติเด่นของระบบ (Key Features)

1. **อัลกอริทึมจัดตารางสอนอัตโนมัติ (CSP + MRV Heuristic)**
   - จัดตารางเรียนครบตามชั่วโมงสอนของหลักสูตรโดยปราศจากข้อขัดแย้ง 100%
   - ตรวจสอบเงื่อนไขบังคับ (Hard Constraints): ครูไม่สอนซ้อนเวลา, ห้องเรียนไม่ถูกใช้ซ้ำ, กลุ่มเรียนไม่เรียนชนกัน, รายวิชาปฏิบัติจัดลงห้องปฏิบัติการ/โรงฝึกงานที่ถูกต้อง
   - ปรับแต่งเงื่อนไขความพึงพอใจ (Soft Constraints): กระจายวิชาตลอดสัปดาห์, ลดคาบว่างระหว่างวันของครู, จำกัดคาบสอนต่อเนื่อง

2. **ระบบเวอร์ชันและการเผยแพร่ตาราง (Version Control)**
   - แยกตารางฉบับร่าง (Draft) ออกจากตารางที่เผยแพร่แล้ว (Published)
   - การจัดตารางใหม่จะไม่เขียนทับตารางที่เผยแพร่แล้วทันที
   - รองรับการคัดลอกตาราง (Duplicate Version) เพื่อนำไปปรับแต่งต่อ

3. **การปรับแต่งตารางแบบผสม (Interactive & Manual Editing)**
   - หน้าต่างแสดงตารางเรียนแบบ Interactive แยกตามกลุ่มเรียน, ครูผู้สอน, และห้องเรียน
   - ฟังก์ชันล็อกคาบเรียน (Lock Slot) เพื่อคงตำแหน่งเดิมเมื่อสั่งจัดตารางอัตโนมัติรอบใหม่
   - ระบบ Pre-check ตรวจสอบความขัดแย้งทันทีก่อนการวางหรือย้ายคาบ

4. **การบริหารจัดการข้อมูลครบวงจร**
   - แผนกวิชา, หลักสูตร ปวช. และ ปวส., กลุ่มเรียน, ครูผู้สอน, รายวิชา, และห้องเรียน/โรงฝึกงาน
   - ตารางกำหนดช่วงเวลาไม่ว่างของครู (Teacher Availability Matrix) รองรับภารกิจศาสนกิจวันศุกร์ (ละหมาดญุมอะฮ์)

5. **ระบบรายงานและการนำเข้า/ส่งออก (Reports & Import/Export)**
   - ส่งออกตารางสอนรายครู รายกลุ่มเรียน และรายห้องเป็นไฟล์ Excel (.xlsx) และ PDF
   - รายงานภาระงานสอนรายสัปดาห์ (Teacher Workload) พร้อมแจ้งเตือนครูที่สอนเกินเกณฑ์
   - รายงานอัตราการใช้งานห้องเรียน (Classroom Utilization Rate)
   - นำเข้าข้อมูลครู รายวิชา และห้องเรียนผ่านไฟล์ Excel พร้อมระบบตรวจสอบความถูกต้องและแจ้งข้อผิดพลาดรายบรรทัด

## 🛠️ สถาปัตยกรรมและเทคโนโลยีที่ใช้ (Tech Stack)

- **Backend**: Node.js, Express.js
- **Database**: SQLite3 (`better-sqlite3`) พร้อมเปิดใช้งาน WAL (Write-Ahead Logging) Mode และ Foreign Keys
- **Authentication**: Session-based Authentication ด้วย `express-session` และ `connect-sqlite3`, รหัสผ่านเข้ารหัสด้วย `bcrypt`
- **Excel & PDF**: `exceljs` และ `pdfmake`
- **Frontend**: Responsive Vanilla HTML5, CSS3 และ Modern JavaScript (Google Fonts: Prompt & Sarabun) ปราศจาก Dependency หนัก โหลดรวดเร็ว แสดงผลลื่นไหล

## 🚀 วิธีติดตั้งและเปิดใช้งานทีละขั้นตอน (Step-by-step Setup)

### 1. ความต้องการของระบบ (Prerequisites)
- ติดตั้ง **Node.js** เวอร์ชัน 18.0 ขึ้นไป
- ติดตั้ง **npm** เวอร์ชัน 9.0 ขึ้นไป

### 2. ติดตั้ง Dependencies
เปิด Terminal ในโฟลเดอร์โปรเจกต์ `pattani-timetable` แล้วรัน:
```bash
npm install
```

### 3. สร้างฐานข้อมูลและนำเข้าข้อมูลจำลอง (Database & Seed)
รันคำสั่งเพื่อสร้างตารางฐานข้อมูลและเตรียมข้อมูลจำลองของวิทยาลัยการอาชีพปัตตานี:
```bash
npm run seed
```
*(ระบบจะสร้างแผนกวิชา, ครู, ห้องเรียน, รายวิชา, กลุ่มเรียน และมอบหมายการสอนเริ่มต้นพร้อมทดสอบทันที)*

### 4. รันการทดสอบระบบอัตโนมัติ (Automated Tests)
ทดสอบความถูกต้องของอัลกอริทึมจัดตารางและระบบตรวจจับข้อขัดแย้ง:
```bash
npm test
```
ผลการทดสอบต้องขึ้น **ผ่านทั้งหมด 100%** โดยไม่มีข้อผิดพลาด

### 5. เริ่มต้นเซิร์ฟเวอร์ (Start Application)
```bash
npm start
```
หรือสำหรับโหมดพัฒนา:
```bash
npm run dev
```

### 6. เข้าใช้งานเว็บไซต์
เปิดเว็บเบราว์เซอร์ไปที่:
👉 **http://localhost:3000**

## 🧪 รายการทดสอบระบบ (Automated Tests Checklist)

- [x] **Teacher Collision**: ครูคนเดียวกันไม่สามารถถูกจัดสอน 2 วิชาพร้อมกันในคาบเดียวกันได้
- [x] **Room Collision**: ห้องเรียนเดียวกันไม่สามารถถูกใช้ซ้ำในคาบเวลาเดียวกันได้
- [x] **Group Collision**: กลุ่มเรียนเดียวกันไม่สามารถเรียน 2 วิชาพร้อมกันได้
- [x] **Teacher Unavailability**: ครูจะไม่ถูกจัดสอนในเวลาที่ระบุว่าไม่ว่าง (เช่น บ่ายวันศุกร์)
- [x] **Lab Requirement**: วิชาปฏิบัติที่ต้องใช้แล็บ จะไม่ถูกจัดในห้องเรียนทฤษฎีทั่วไป
- [x] **Locked Slot Preservation**: คาบเรียนที่ถูกกดล็อก (Lock) จะคงตำแหน่งเดิมเสมอเมื่อสั่งจัดตารางใหม่
- [x] **Published Protection**: ระบบไม่อนุญาตให้เขียนตารางทับเวอร์ชันที่เผยแพร่แล้ว
